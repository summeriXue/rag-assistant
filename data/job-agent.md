# Job Agent

Job Agent 是一个用于辅助求职流程的 AI Agent。

## Job Search

Job Agent 可以从多个招聘平台搜索职位。

search_jobs:
用于根据职位关键词搜索岗位。

## Validation

Job Agent 可以检查职位记录是否包含必要信息。

validate_job_record:
用于检查公司、岗位名称和职位来源等字段。

## Conversation Continuation

当一次职位搜索因平台限制而中断时，
Job Agent 可以继续从其他招聘来源进行搜索。

continue_job_search:
用于从剩余招聘来源继续职位搜索。
